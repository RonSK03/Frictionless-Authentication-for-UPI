Conducted research on Frictionless Authentication for UPI-Based Digital Payments using Behavioural
Biometrics from KMT interactions (keyboard, mouse & touch). Developed and evaluated Few-Shot
Learning (FSL) models including Siamese Networks & Prototypical Networks on a feature-engineered
KMT dataset along with a hybrid LSTM-SVM model on raw time-series data. Optimized required
thresholds using security metrics and achieved 87% authentication accuracy with 8.6% false
acceptance rate with Prototypical Networks.
